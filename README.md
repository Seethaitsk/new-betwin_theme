# Betwin Games - Online Casino & Aviator Next.js Theme

Customized Next.js 14 template for **Betwin Games Namibia**, featuring Aviator crash game, online slots, Lucky 6, bingo, and sports betting.

## Features

- **Next.js 14 (App Router)** with TypeScript
- **Red Theme Styling** (`#E3073C` primary brand accents)
- **Top Rated Games Slider** with portrait poster cards and hover effects
- **Interactive Why Choose Betwin** 2-column showcase
- **Step-by-Step How to Play Aviator Guide** (Roadmap)
- **Responsive Navigation** with centered header menus and mobile drawer
- **Favicon & Brand Assets** for Betwin Games

## Getting Started

### Development Server

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build

Build and start the application for production:

```bash
npm run build
npm run start
```

## Project Structure

- `src/app/`: Next.js App Router layout and pages (SSR / Static Generation / Metadata)
- `src/views/`: Interactive view components
- `src/components/`: Reusable React components (Hero, Games slider, Why Choose, Roadmap, About, etc.)
- `src/data/`: Data sources for games, menus, and content
- `public/`: Static assets (images, fonts, SCSS/CSS, audio)
